\section{Обзор системы}

\subsection{Назначение}

Система представляет собой веб-приложение с бэкендом на FastAPI и фронтендом на React (TypeScript). Основные пользователи~--- студенты: они загружают PDF-файлы (шаблоны ВКР или отчёты по практике), указывают тип документа и получают отчёт с результатами автоматической формальной проверки (предупреждения, ошибки). Дополнительно предусмотрен интерфейс на основе электронной почты: обработка входящих писем с заданными темами, извлечение PDF из вложений и автоматическая отправка студентам отчётов с результатами проверки.

\subsection{Основные функции}

Пользователь загружает один или несколько PDF-файлов, указывает для каждого тип документа (шаблон ВКР или отчёт по практике). Система выполняет проверку формальной корректности по правилам, соответствующим выбранному типу, и выводит отчёт о прохождении/непрохождении проверок. Результаты можно экспортировать; по каждому документу доступен просмотр PDF и список замечаний.

\subsection{Доступ и развёртывание}

Доступ к сервису осуществляется через защищённый веб-интерфейс. Аутентификация предпочтительно выполняется через \textbf{itmo.id} (интеграция с учётными данными ИТМО). Сервис развёртывается на инфраструктуре Университета ИТМО; перед приложением используется обратный прокси \textbf{Nginx}. Загрузки PDF проходят проверку безопасности: не допускаются файлы с признаками вредоносного ПО, исполняемого кода или PDF-эксплойтов.
