\section{Требования к данным}

\subsection{Сущности}

\begin{itemize}
  \item \textbf{Пользователи:} идентификатор, ссылка на учётную запись itmo.id (или аналог), имя, email, роль.
  \item \textbf{Документы:} идентификатор, тип (шаблон ВКР / отчёт по практике), путь к файлу в S3-совместимом хранилище, дата загрузки, идентификатор пользователя, статус проверки, результат проверки (JSON или структурированное представление).
\end{itemize}

\subsection{Хранение}

Файлы PDF хранятся в \textbf{S3-совместимом} хранилище с уникальными именами или путями, исключающими конфликты. Метаданные и результаты проверки хранятся в СУБД \textbf{PostgreSQL}; доступ к БД со стороны бэкенда~--- асинхронный (драйвер asyncpg).

\subsection{Хранение и удаление}

Срок хранения загруженных документов и связанных данных настраивается (например, один учебный год). По истечении срока данные могут архивироваться или удаляться в соответствии с политикой ИТМО.
