\section{Критерии приёмки}

Система считается соответствующей данной спецификации при выполнении следующих условий:

\begin{enumerate}
  \item Реализована загрузка PDF с указанием типа документа (шаблон ВКР / отчёт по практике), в том числе пакетная загрузка.
  \item Выполняется проверка безопасности загружаемых PDF: файлы с признаками вредоносного ПО, исполняемого кода или PDF-эксплойтов не принимаются; при отклонении пользователь получает однозначное сообщение об ошибке.
  \item Проверка шаблона ВКР покрывает структуру и оформление в соответствии с документом ИТМО.
  \item Проверка отчёта по практике покрывает формальное оформление и структуру (этапы, скриншоты) в соответствии с заданием.
  \item Результаты проверки отображаются наглядно; реализован экспорт отчёта; система автоматически формирует и предоставляет отчёт с результатами (предупреждения, ошибки); ручная проверка и комментарии преподавателя не предусмотрены.
  \item Аутентификация выполняется через itmo.id (или согласованный механизм); сервис работает на инфраструктуре ИТМО за обратным прокси Nginx.
  \item Непрерывная интеграция и развёртывание~--- согласно разделу «Архитектура системы».
  \item Стек бэкенда и фронтенда соответствует описанному в разделе «Архитектура системы».
\end{enumerate}
